# Snello Layouts

Prototipo Angular zoneless per comporre layout Formly su metadati Snello.

Le API di prova sono `https://api.sne.lol/api`. Il configuratore è protetto da Keycloak, realm `snello`, client `snello-admin`. I layout salvati restano in `localStorage`.

```bash
npm start
```

Poi apri `http://localhost:4200`. Il redirect di login deve essere consentito sul client `snello-admin`.
